# nexos.ai Finance Cockpit

An illustrative finance leadership dashboard by Karolis Mazeika (Finance Director), covering FP&A, revenue accounting, scenario planning, record-to-report, and tax compliance.

All figures and company examples are fictional and provided for demonstration purposes.

## Netlify deployment

Netlify reads the included `netlify.toml` automatically. The production build uses Node.js 22, runs `npm run build:netlify`, and publishes the generated `out` directory.
